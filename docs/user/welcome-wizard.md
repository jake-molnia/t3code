# Get started

Open your deployment's address and authorize your browser with a pairing link when prompted. Setup takes you to your existing projects or the new-project screen. You do not need to install a server or connect a machine.

Create or import a project to start a conversation. Each new top-level thread gets its own sandbox workspace. Delegated agents share the parent thread's workspace. Your projects and conversations remain in the central service.

Choose a provider account and model in **Settings → Providers**. Provider binaries come from the deployment image.

## Choose an execution pool

Choose Gompers or Portal from the pool menu before sending a new thread. In **Settings → Connections → Execution pools**, enable automatic load balancing to route new threads using available CPU, memory, and each pool's preference. **Manual only** excludes a pool from automatic routing while keeping it available for explicit selection.

If no pool is available, your conversations remain accessible. Contact the deployment administrator to restore execution.
