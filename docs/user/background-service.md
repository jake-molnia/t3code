# Keep T3 Code running

The deployment runs the central T3 service independently of your browser. Closing a tab does not stop the service or remove saved conversations.

Your deployment administrator manages service startup, restarts, and execution lifecycle. If the application is unavailable, contact them with the error and time of the failure.

For administrator setup, follow the [native sandbox deployment guide](../../deploy/t3/README.md). For maintenance, see [updates](./updating.md).
